# products/ — Ảnh từng sản phẩm cụ thể (tùy chọn)

Thư mục này dùng chung cho **tất cả** thẻ sản phẩm nhỏ trên toàn site (trang chủ, các trang ngành, trang Lọc chất lỏng, trang Lọc khí & Sàng lọc) — có 36 thẻ sản phẩm khác nhau.

**Đây là mục tùy chọn, ưu tiên thấp nhất.** Nếu không có ảnh, các thẻ sản phẩm vẫn hiển thị icon minh họa rõ ràng, đẹp mắt như hiện tại — không bắt buộc phải chụp đủ 36 ảnh. Bạn có thể chỉ bổ sung ảnh cho vài sản phẩm chủ lực trước, phần còn lại thêm dần sau.

## Cách đặt tên file

Mở file **`PRODUCT_LIST.txt`** trong thư mục này — file đó liệt kê chính xác 36 tên file cần dùng, tương ứng với tên sản phẩm hiển thị trên site. Chỉ cần đặt tên file ảnh đúng như cột bên trái của danh sách đó.

Ví dụ: sản phẩm "Lõi lọc Melt-blown" → đặt tên file `loi-loc-melt-blown.jpg`

- **Tỷ lệ khung hình:** 16:11 (ảnh sản phẩm hơi ngang)
- **Kích thước khuyến nghị:** tối thiểu 640×440px
- **Nội dung gợi ý:** ảnh chụp sản phẩm trên nền trung tính/trắng, ánh sáng đều, giống ảnh catalogue kỹ thuật
- **Định dạng:** `.jpg` / `.jpeg` / `.png` / `.webp`
